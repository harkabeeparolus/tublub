# Security Policy

## Supported Versions

Only the latest release of tublub receives security updates.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately via
[GitHub private vulnerability reporting](https://github.com/harkabeeparolus/tublub/security/advisories/new)
rather than opening a public issue. You should normally get a response within
a couple of weeks; this is a hobby project maintained in spare time.
