# Code of Conduct

tublub follows the
[Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful.

Instances of unacceptable behavior may be reported to the maintainer,
[@harkabeeparolus](https://github.com/harkabeeparolus).
